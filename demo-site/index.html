This is a mock customer website to test the SitePulse embeddable widget. Look at the bottom-right corner to see the widget in action!

Embedded Script Details

Notice how easy it was to install: just one script tag in the HTML head:

<script src="http://localhost:5000/sitepulse.js" data-site-key="sp_demo_12345" defer></script>

The widget loads via Shadow DOM so it never conflicts with the host page CSS styles.
